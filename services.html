AWS Lambda Services

AWS Lambda is a serverless compute service from Amazon Web if you need a code to be checked automatically AWS Lambda can do that making sure it's done correctly and only charges for execution time. What makes it advanced and the best service is it manage scaling, patching, and fault tolerance making it suitable for per-user sessions, AI workloads and human in the loop processes which is mainly used in KInesis, kafka, SQS, DYnamoDB streams.

Elastic Compute Cloud services

The Amazon EC2 also known as Elastic Compute cloud providing virtual servers that range in configuration and are equipped with different CPUs like memory and networking capacities to run various operating systems like small databases, Balanced general instances, optimized for CPU-heavy task projects automatically adjusting complete cloud solutions.
